# ¿Wakarú? · 分かる？

Compañero para aprender japonés hablando: conversación por voz y por escrito, corrección de cada frase, vocabulario propio con repetición espaciada y explicación de kanji.

- Funciona en el navegador y se instala como app (Android, iPhone y ordenador).
- La conversación usa la API de Google Gemini con tu propia clave gratuita (https://aistudio.google.com/apikey). La clave se guarda solo en tu dispositivo.
- Reconocimiento y voz japonesa: los del propio dispositivo (gratis).
- El progreso se guarda en el dispositivo; se puede exportar e importar desde Ajustes.

Hecho como app web estática: `index.html`, `manifest.webmanifest`, `sw.js` e iconos. Se publica con GitHub Pages.

## Créditos

- Diccionario: lista de palabras de los niveles JLPT N5–N3 basada en [JMdict](https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project) (© Electronic Dictionary Research and Development Group, licencia CC BY-SA 4.0), con los niveles de [open-anki-jlpt-decks](https://github.com/jamsinclair/open-anki-jlpt-decks). Traducción al español propia para esta app. El archivo `dict-ja-es.json` se distribuye bajo CC BY-SA 4.0.
- Conversión romaji → kana: [WanaKana](https://github.com/WaniKani/WanaKana) (MIT).
